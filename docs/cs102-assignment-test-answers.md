## Assignment 1
题目：栈与队列的特性比较及应用分析

### 高质量答案（分点格式）
1. 栈和队列的核心区别在于访问顺序不同。栈遵循后进先出（LIFO），最后进入的数据最先被取出；队列遵循先进先出（FIFO），最早进入的数据最先被取出。
2. 栈适用于函数调用栈或括号匹配。因为函数调用具有“后调用先返回”的特点，和栈的后进先出一致。队列适用于打印任务排队或广度优先搜索，因为这些场景都要求先到的任务先处理。
3. 顺序存储实现栈时结构简单、缓存友好，但容量受数组大小限制；链式存储扩展灵活，但需要额外指针空间。顺序队列若设计成循环队列则效率较高，链式队列则更适合频繁入队出队且规模变化较大的情况。

### 中等答案（自然段格式）
栈和队列都属于线性结构，但是它们处理数据的顺序不同。栈是后进先出，比如撤销操作或者函数调用；队列是先进先出，比如排队打印或者消息等待处理。顺序结构实现起来比较直接，但容量变化不灵活；链式结构更容易扩展，不过会增加指针开销。

### 低质量答案（错误示例）
栈和队列没有本质区别，都是随便存和随便取。它们都适合做排序，也都不需要考虑顺序问题。一般来说只要把数据放进去就行，不需要考虑应用场景。

## Assignment 2
题目：二叉树遍历结果分析与结构重建

### 高质量答案（结构化推导）
已知前序遍历为 A B D E C F，中序遍历为 D B E A C F。

1. 前序遍历第一个结点 A 一定是根结点。
2. 在中序序列中，A 左边的 D B E 属于左子树，A 右边的 C F 属于右子树。
3. 左子树的前序是 B D E，因此左子树根为 B；中序 D B E 说明 B 的左孩子是 D，右孩子是 E。
4. 右子树的前序是 C F，中序是 C F，因此右子树根为 C，C 没有左孩子，右孩子为 F。

因此树结构为：

```text
        A
      /   \
     B     C
    / \     \
   D   E     F
```

后序遍历结果为：D E B F C A。

### 中等答案（简洁版）
根结点是 A，因为前序第一个就是根。中序里 A 左边是左子树，右边是右子树。左子树根是 B，孩子是 D 和 E；右子树根是 C，右孩子是 F。所以后序遍历是 D E B F C A。

### 低质量答案（错误示例）
因为前序遍历是 A B D E C F，所以这棵树一定是一条链。后序遍历应该和中序一样，所以答案是 D B E A C F。

## Assignment 3
题目：单链表逆置的伪代码实现与复杂度说明

### 高质量答案（伪代码格式）
```text
prev = null
curr = head
while curr != null:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
head = prev
```

说明：
- `prev` 指向已经逆置好的前半段链表头结点。
- `curr` 指向当前正在处理的结点。
- `next` 用来暂存 `curr.next`，防止链断开后无法继续遍历。
- 每轮循环都把 `curr` 的指针反向，再整体向前推进。
- 时间复杂度为 `O(n)`，因为每个结点只访问一次；空间复杂度为 `O(1)`，因为只用了常数个辅助指针。

### 中等答案（自然段 + 少量代码）
可以用三个指针完成单链表逆置，分别是前驱指针、当前指针和后继指针。每次先保存后继结点，再把当前结点的 `next` 指向前驱，然后整体后移。这样遍历完链表后，前驱指针就会指向新的头结点。这个算法时间复杂度是 `O(n)`，空间复杂度是 `O(1)`。

### 低质量答案（错误示例）
单链表逆置只要把头结点删掉再重新插入到尾部就可以了，复杂度大概是 `O(1)`。不需要额外指针，只需要一直交换数据内容。

## Assignment 4
题目：图遍历与最短路径算法选择

### 高质量答案（对比表述）
BFS 和 DFS 都是图遍历方法，但访问策略不同。BFS 按层扩展，通常借助队列实现，适合无权图最短路径、层次遍历等问题；DFS 优先向深处探索，通常借助递归或栈实现，适合连通分量分析、回溯搜索、拓扑相关问题。

Dijkstra 算法适用于边权非负的单源最短路径问题，因为它依赖“当前已确定的最短距离不会再被更小值更新”的贪心假设。如果图中存在负权边，这个前提不成立，Dijkstra 可能得到错误结果。

若边权可能为负，应优先考虑 Bellman-Ford 一类算法，因为它能够逐轮松弛边，并可以进一步检测负权回路。

### 中等答案（分段回答）
1. BFS 是一层一层找，DFS 是一条路先走到底再回退。
2. Dijkstra 适合边权都不是负数的时候求最短路径。
3. 如果有负权边，就不要用 Dijkstra，应该考虑 Bellman-Ford。

### 低质量答案（错误示例）
BFS 和 DFS 基本一样，只是名字不同。Dijkstra 适用于所有最短路径问题，包括负权边和负环，因为它速度最快，所以总是最优选择。
