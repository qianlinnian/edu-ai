  - `ILF = 14`
  - `EIF = 5`
  - `EI = 10`
  - `EO = 6`
  - `EQ = 3`

  - `UFP = 205`
  - `VAF = 1.11`

## 第 11 页 课程项目的经济评估

**覆盖课程要求**：`9 Economic evaluation of the course project`

**要点**

- 经济评估采用 3 年期现金流分析模型，收入来源设定为：
  - 课程年服务费
  - 定制化配置服务费
- 收入假设为：
  - 第 1 年：`6` 门课 + `1` 次定制，总收入 `72,000 元`
  - 第 2 年：`12` 门课 + `2` 次定制，总收入 `144,000 元`
  - 第 3 年：`22` 门课 + `4` 次定制，总收入 `268,000 元`
- 初始总投资约 `289,145.38 元`，包含开发成本、初始部署与营运资金。
- 预融资分析结果：
  - `NPV = 2697.16 元`
  - `IRR ≈ 8.40%`
  - `DPP ≈ 2.98 年`
- 融资后分析结果：
  - `Equity NPV = 9696.22 元`
  - `Equity IRR ≈ 10.14%`
  - `DPP ≈ 2.96 年`
- 结论应表述为：项目具备**一定经济可行性**，但不是短期高回报项目，其可行性依赖课程覆盖扩大、平台复用提升和模型/运维成本控制。
