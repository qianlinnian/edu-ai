## 场景一：Widget 流式问答

**测试时间**: 2026-05-31 19:00
**测试结果**: ✅ 通过（部分）- 收到 90 个 chunk 后 LLM 返回空内容

**请求信息**:
```
接口: POST /api/v1/chat/send-stream
Content-Type: application/json
Authorization: Bearer [TOKEN]
```

**请求体**:
```json
{
  "agent_id": 3,
  "course_id": 3,
  "session_id": null,
  "message": "请解释什么是闭包？"
}
```

**响应事件序列**:
```
data: {"type":"chunk","content":"在..."}
data: {"type":"chunk","content":"Python中..."}
data: {"type":"chunk","content":"闭包是一个..."}
... (共 90 个 chunk)
data: {"type":"error","error":"DashScope API error: function(chat_stream) - empty content in response"}
```

**响应摘要**:
- 总 chunk 数: 90
- 完整内容: "在Python中，闭包（Closure）是一个非常强大且常用的概念。简单来说，闭包是一个..."
- Done 事件: 未收到（LLM API 返回空内容）
- 错误类型: LLM API 偶发性空响应

**数据库证据**:
```sql
SELECT * FROM chat_sessions ORDER BY created_at DESC LIMIT 5;
-- session_id: 7
```

**验证口径对照**:
| 验证项 | 口径要求 | 实际结果 | 状态 |
|--------|----------|----------|------|
| 流式事件格式 | `{"type":"chunk","content":"..."}` | ✅ 符合 | ✅ |
| 错误处理 | `{"type":"error","error":"..."}` | ✅ 符合 | ✅ |
| session_id 创建 | 首次请求时自动创建 | ✅ 符合 | ✅ |

**问题记录**: LLM API (DashScope) 偶发性返回空内容，建议增加重试机制。

**测试时间**: 2026-05-31 19:00
**测试结果**: ✅ 通过

**测试步骤**:
1. 进入 Agent Builder 页面
2. 添加/调整节点
3. 配置 RAG 节点参数
4. 点击保存按钮

**API 调用 1 - 创建实例**:
```
POST /api/v1/agents/instances
```

**请求体**:
```json
{
  "template_id": null,
  "course_id": 3,
  "name": "Python课程答疑Agent",
  "description": "由 M4 测试创建",
  "system_prompt": "你是一个智能教学助手。",

  "llm_provider": "dashscope",
  "llm_model": "qwen-max"
}
```

**响应**:
```json
{
  "id": 8,
  "name": "Python课程答疑Agent",
  "description": "由 M4 测试创建",
  "course_id": 3,
  "llm_provider": "dashscope",
  "llm_model": "qwen-max",
  "is_active": true
}
```
