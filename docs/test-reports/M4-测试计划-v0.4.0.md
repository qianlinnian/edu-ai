## 3. 端到端测试场景

### 3.1 场景一：Widget 流式问答

**测试目的**: 验证 Widget 组件通过流式接口进行实时问答

**测试步骤**:
1. 打开 Widget 页面 `http://localhost:5173/widget?course=1`
2. 输入问题：`请解释什么是 Python 装饰器？`
3. 点击发送按钮
4. 观察流式响应展示

**预期结果**:
- 消息以流式方式逐步展示
- 响应内容包含课程相关知识
- 页面样式正常渲染

**验证口径**:
- 请求: `POST /api/v1/chat/send-stream`
  ```json
  {
    "agent_id": 1,
    "course_id": 1,
    "session_id": 12,
    "message": "请解释什么是 Python 装饰器？"
  }
  ```
- 事件顺序: `chunk` → `done` 或 `error`

### 3.5 场景五：Agent Builder 保存流程

**测试目的**: 验证工作流构建器保存到后端

**测试步骤**:
1. 进入 Agent Builder 页面
2. 调整工作流节点
3. 配置 RAG 节点（关联课程、Top-K、相似度）
4. 点击保存/发布按钮

**预期结果**:
- 调用 `POST /api/v1/agents/instances`
- 调用 `POST /api/v1/agents/workflows`
- `workflow_dag` 包含 `nodes` 和 `edges`

**验证口径**:
```json
{
  "agent_id": 1,
  "name": "Python课程答疑Agent 工作流",
  "workflow_dag": {
    "nodes": [
      {
        "id": "n2",
        "type": "custom",
        "position": { "x": 250, "y": 160 },
        "data": {
          "label": "知识检索",
          "color": "#00a8ff",
          "icon": "🔍",
          "nodeType": "rag_node",
          "course": 1,
          "topK": 5,
          "similarity": 0.7
        }
      }
    ],
    "edges": []
  }
}
```

### 3.6 场景六：平台模拟接口

#### 3.6.1 超星 LTI 启动

**测试目的**: 验证超星平台启动接口

**测试步骤**:
1. 调用 `POST /api/v1/platform/chaoxing/lti-launch`

**验证口径**:
```bash
curl -X POST http://localhost:8000/api/v1/platform/chaoxing/lti-launch \
  -H "Content-Type: application/json" \
  -d '{"resource_link_id": "res-001", "user_id": "user-123", "roles": "student"}'
```

**预期响应**:
```json
{
  "platform": "chaoxing",
  "status": "success",
  "widget_url": "/widget?platform=chaoxing&resource=res-001",
  "session": { ... }
}
```

**错误场景**: 缺少 `resource_link_id` 时返回明确错误

#### 3.6.2 钉钉免登授权

**测试目的**: 验证钉钉平台登录接口

**测试步骤**:
1. 调用 `GET /api/v1/platform/dingtalk/auth?code=demo-code&course_id=1`

**验证口径**:
```bash
curl "http://localhost:8000/api/v1/platform/dingtalk/auth?code=demo-code&course_id=1"
```

**预期响应**:
```json
{
  "platform": "dingtalk",
  "status": "success",
  "widget_url": "/widget?platform=dingtalk&course=1",
  "session": { ... }
}
```

**错误场景**: 缺少 `code` 参数时返回明确错误
