# EduAI 课程 Agent 使用场景定义

## 1. 文档目的

本文档用于明确 EduAI 项目中“课程 Agent”的当前定位、教师端与学生端的使用方式，以及该能力与现有系统模块的对应关系。

本文档对应 WBS 任务 `2.4 课程 Agent 使用场景定义`，用于回应里程碑评审中“教师端 AI 使用场景不够明确”的问题。

## 2. 当前实现定位

当前版本中，教师端与学生端 **共用同一套课程知识问答 Agent 能力**。  
该 Agent 的核心能力不是角色专属工作流，而是：

- 基于课程资料的知识问答
- 基于 RAG 的课程上下文检索
- 基于会话历史的连续对话

因此，当前阶段教师端和学生端的主要差异 **不在 Agent 算法或模型能力本身**，而在于使用者的目标不同。

## 3. 课程 Agent 的统一能力边界

课程 Agent 当前负责以下能力：

- 接收用户问题并结合课程资料进行回答
- 优先使用当前课程知识库中的资料作为回答依据
- 在同一会话中保留上下文，支持连续问答
- 只在当前课程范围内检索资料，不跨课程混用内容

课程 Agent 当前 **不等同于** 以下专门教学工作流：

- 自动参考答案校验 Agent
- 自动学情总结 Agent
- 自动作业知识点检查 Agent

上述能力可以作为后续扩展方向，但不应视为当前阶段已独立实现的教师端专属 Agent。

## 4. 学生端使用场景

学生端使用课程 Agent 的主要目标是辅助学习。当前典型场景包括：

1. 课程概念问答
- 例如：解释某个知识点、语法规则、算法步骤或公式含义

2. 基于课程资料的答疑
- 例如：根据上传课件、讲义、实验资料回答“老师课上是怎么定义的”

3. 复习与理解支持
- 例如：让 Agent 对某个概念做简化解释、举例说明、对比易混点

4. 练习前准备
- 例如：在做作业或练习前先询问相关背景知识

## 5. 教师端使用场景

教师端使用课程 Agent 的主要目标是辅助备课和快速核对课程知识内容。当前典型场景包括：

1. 课程资料内容查阅
- 教师可直接通过问答方式快速定位某门课程资料中的概念、定义、步骤或案例

2. 知识点表述确认
- 教师可询问某个知识点在当前课程资料中的表述方式，用于备课、自查或统一口径

3. 教学问答准备
- 教师可提前验证学生可能提出的问题是否能被当前课程资料支撑回答

4. 作业与练习辅助参考
- 教师可先通过课程 Agent 查询相关知识背景，再开展作业设计、参考答案编写或练习准备

需要说明的是：  
教师端当前并不是通过一个“专门的教师 Agent”完成自动化教学管理，而是使用同一课程知识问答 Agent 作为教学辅助工具。

## 6. 教师端与学生端差异说明

当前教师端与学生端的差异主要体现在使用目的上：

| 维度 | 学生端 | 教师端 |
| :--- | :--- | :--- |
| 核心目标 | 学习、理解、复习、答疑 | 备课、查阅、确认、辅助准备 |
| Agent 能力 | 共用课程知识问答 Agent | 共用课程知识问答 Agent |
| 资料来源 | 当前课程知识库 | 当前课程知识库 |
| 会话机制 | 按课程和用户保存 | 按课程和用户保存 |

因此，当前版本中两端是“**同能力、不同目的**”的关系，而不是“**两套完全不同的 Agent**”。

## 7. 与现有系统模块的对应关系

课程 Agent 使用场景与当前系统实现的对应关系如下：

| 场景 | 当前模块 | 说明 |
| :--- | :--- | :--- |
| 课程知识问答 | `chat` | 提供课程内问答与会话管理 |
| 课程资料检索 | `RAG / ResourceChunk / embedding` | 提供基于课程资料的上下文检索 |
| 会话连续对话 | `chat session` | 保存课程范围内的聊天记录 |
| 课程范围隔离 | `course_id` 绑定 | 保证问答仅使用当前课程资料 |

## 8. 当前限制

当前版本存在以下限制：

- 教师端和学生端尚未分化为两套独立 Agent 工作流
- 教师端尚未提供专门的“知识点检查 / 学情总结 / 参考答案校验”结构化入口
- 当前教师端对课程 Agent 的使用主要仍体现为知识问答，而不是自动化教学决策

这些限制不影响课程 Agent 作为“课程知识问答入口”的成立，但需要在汇报和验收中明确说明，避免将后续扩展能力误写为当前已完成能力。

## 9. 后续扩展方向

在后续版本中，课程 Agent 可进一步扩展为更明确的教师端教学辅助能力，例如：

- 面向作业的知识点覆盖检查
- 面向 rubric 的参考答案核对建议
- 面向学情数据的薄弱点总结
- 面向课程知识库的练习设计建议

上述内容属于后续可扩展方向，不属于当前版本 `2.4` 的已交付范围。

## 10. 结论

当前 EduAI 中的课程 Agent 已形成统一的课程知识问答能力。  
教师端与学生端共用同一能力底座，差异主要体现在使用目的：

- 学生端面向学习问答
- 教师端面向备课查阅和知识确认

因此，`2.4 课程 Agent 使用场景定义` 的正式产物应当是对这一能力定位和场景边界的明确说明，而不是虚构一套当前尚未实现的教师专属 Agent 流程。
