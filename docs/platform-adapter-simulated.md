# 平台适配说明（模拟接入口径）

更新时间：2026-06-05
负责人：综合 D

---

## 1. 文档目的

本文档用于统一 EduAI 当前版本在平台适配方向的对外表述，避免把“已完成的模拟接入闭环”说成“已完成真实平台生产联调闭环”。

适用对象：
- 答辩材料编写
- 演示讲解
- 测试记录引用
- 交付材料口径统一

---

## 2. 当前已完成内容

当前平台适配已完成的是“模拟接入闭环”，包括：

### 2.1 超星方向

已提供接口：
- `POST /api/v1/platform/chaoxing/lti-launch`

当前能力：
- 接收启动参数
- 校验关键字段
- 生成并返回 `widget_url`
- 支持前端 Widget 页面完成演示链路

### 2.2 钉钉方向

已提供接口：
- `GET /api/v1/platform/dingtalk/auth`

当前能力：
- 接收 `code` 与课程参数
- 完成模拟认证返回
- 生成并返回 `widget_url`
- 支持前端 Widget 页面完成演示链路

### 2.3 字段来源统一定义

- `widget_url`：由 EduAI 后端生成，格式为 `/widget/chat?course={course_id}&token={embed_token}`
- `token`：由 EduAI 后端签发，不由上游平台直接提供
- `course_id`：由上游平台请求参数提供
- `role`：由上游平台请求参数提供
- `launch_ticket` / `auth_code`：由上游平台请求参数提供，仅用于模拟接入上下文，不做真实签名校验

### 2.4 当前可对外表述

建议统一表述为：

- 已完成超星、钉钉方向的模拟接入接口与嵌入演示闭环
- 已具备平台入口 -> 后端处理 -> Widget 启动 的演示能力
- 当前版本支持平台适配方案验证与演示，不等同于真实生产联调完成

---

## 3. 当前未完成内容

以下内容不应在答辩或文档中表述为“已完成”：

### 3.1 真实平台联调

当前未证明：
- 与真实超星平台完成正式 LTI 联调
- 与真实钉钉环境完成正式免登联调
- 真实生产环境下的稳定性验证

### 3.2 真实签名与安全校验链路

当前未形成完整闭环：
- 真实平台签名校验
- 完整鉴权回调链路
- 生产级安全审计与异常追踪

### 3.3 业务回流链路

当前未形成完整闭环：
- webhook 事件真正回写业务系统
- 成绩回传
- 预警回传
- 平台侧学习行为数据回流

其中钉钉 webhook 当前仅为占位响应，不应表述为已完成真实业务接入。

## 4. 推荐答辩说法

### 4.1 推荐说法

- 当前平台适配已经完成模拟接入闭环。
- 我们已经实现了超星和钉钉两个方向的启动/认证入口，并能拉起 Widget 完成演示链路。
- 当前版本重点验证的是标准化接入接口与嵌入能力。
- 真实平台联调、真实签名校验以及 webhook/成绩/预警回流，属于下一阶段部署联调工作。

### 4.2 不推荐说法

避免使用以下表述：
- 已与超星完成正式对接
- 已与钉钉完成生产联调
- 已完成平台数据回流
- 已完成完整平台闭环上线
